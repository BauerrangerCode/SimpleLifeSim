# Multiplayer

**Status:** Skeleton - not yet written

## Decided

- Co-op for up to 2 players.
- Online: players connect to a dedicated server.
- Local split-screen: a local dedicated server runs in the background and both local players connect to it.
- One network architecture (client / dedicated server), no separate offline path.
- Server is authoritative.
